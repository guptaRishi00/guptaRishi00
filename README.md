## About

I like the parts of a product most people skip: the checkout that must never oversell, the auth check that has to live in every server action, the file format that has to survive a crash halfway through a write. I care just as much about how the result looks and moves.

- **MERN**, as I define it: **M**ostly **E**diting **R**andom **N**ode modules.
- I speak fluent React and slightly broken English.
- Off the clock I make photorealistic AI images and composite them into video with Python and OpenCV.
